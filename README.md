# Instagram Carousel Generator 🎨

Полнофункциональное веб-приложение для генерации красивых editorial каруселей для Instagram с поддержкой русского языка.

## ✨ Основные возможности

### 1. **Bulk Generator**
- Большое текстовое поле для вставки сырого текста
- Автоматическое разбиение на слайды по структуре: `### Заголовок` → `## Подзаголовок` → Тело текста
- Умная обработка текста: автоматическое убирание висячих предлогов/союзов в конце строк
- Предварительный просмотр структуры слайдов

### 2. **Slide Editor (боковая панель)**
- Редактирование текста каждого слайда отдельно
- Загрузка фоновых изображений (drag-and-drop или file input)
- Переключение между 4 уникальными макетами
- Контроль размера шрифта с автоадаптацией при переполнении

### 3. **Layouts System**
- **Центрированный** - классический макет с текстом по центру
- **Слева** - левостороннее выравнивание для акцента
- **Разделённый** - двухсекционный дизайн
- **Угловой акцент** - современный макет с декоративным углом
- Рандомное смещение/поворот текстовых блоков (в разумных пределах)
- Минималистичные геометрические элементы (SVG дудлы)

### 4. **Preview**
- Отображение текущего слайда размером **1080x1350px** (Instagram формат)
- Умное масштабирование для помещения на экран (fit-to-screen)
- Реальное превью того, как будет выглядеть финальный слайд
- Быстрая навигация между слайдами (стрелки/клавиатура)

### 5. **Export**
- Кнопка "Скачать все" для экспорта всех слайдов в PNG
- Высокое качество изображений (2x pixel ratio)
- Понятная индикация прогресса при экспорте

## 🚀 Технологический стек

- **React 18** + **TypeScript**
- **Vite** - современный и быстрый сборщик
- **Tailwind CSS** - утилитарные стили
- **lucide-react** - красивые иконки
- **html-to-image** - экспорт в PNG
- **Google Fonts (Inter)** - поддержка русских шрифтов

## 🎯 Использование

### Создание слайдов из текста (Bulk Generator)

1. Нажмите на кнопку "Создать слайды из текста"
2. Вставьте текст в формате:
```
### Заголовок первого слайда
## Подзаголовок
Основной текст слайда.

### Заголовок второго слайда
## Подзаголовок
Основной текст второго слайда.
```
3. Нажмите "Создать слайды"

### Редактирование слайда

1. Выберите слайд с помощью навигации (стрелки)
2. В боковой панели редактируйте:
   - Заголовок
   - Подзаголовок
   - Основной текст
   - Размер шрифта
   - Макет
   - Фоновое изображение

### Экспорт слайдов

1. Нажмите кнопку "Скачать все"
2. Подождите завершения экспорта
3. Все слайды будут скачаны в формате PNG

## 🎨 Примеры макетов

Приложение включает 4 предустановленных макета, каждый с уникальным дизайном:
- Рандомизация положения элементов в safe zone
- Минималистичные SVG дудлы для декора
- Поддержка кастомных фоновых изображений

## 🔧 Технические детали

### Автоадаптация шрифта
Если текст выходит за границы слайда, размер шрифта автоматически уменьшается (минимум 12px).

### Умная обработка текста
Система автоматически убирает висячие предлоги и союзы в конце строк для лучшей читаемости.

### Рандомизация
Элементы имеют случайное смещение и поворот, но в пределах safe zone для сохранения читаемости.
