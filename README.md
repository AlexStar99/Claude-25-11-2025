# Система учёта финансов отеля 🏨

Веб-приложение для ежедневного учёта финансов отеля на основе отчётов из PMS системы bnovo.ru с полной поддержкой русского языка.

## ✨ Основные возможности

### 1. **Dashboard - Панель управления**
- Ключевые финансовые показатели (выручка, расходы, чистая прибыль)
- Метрики эффективности (ADR, RevPAR, загруженность)
- Статистика по гостям и бронированиям
- Процент отмен и долги
- Сводка по всем категориям номеров

### 2. **Импорт данных**
- Удобная форма для ввода данных из отчётов bnovo.ru
- Поддержка всех категорий номеров (Семейный, Комфорт, Стандарт)
- Автоматический расчёт суммарных показателей
- Ввод бухгалтерских данных (платежи, расходы)
- Выбор периода отчёта

### 3. **Список отчётов**
- Просмотр всех сохранённых отчётов
- Детальная информация по каждому отчёту
- Удаление ненужных отчётов
- Фильтрация и поиск по периодам

### 4. **Детальный анализ**
- Сравнение с предыдущими периодами
- Детальная статистика по категориям номеров
- Визуализация загруженности
- Анализ прибыльности по категориям
- Графики и диаграммы

### 5. **Хранение данных**
- Автоматическое сохранение в localStorage
- Работа без интернета
- Быстрый доступ к историческим данным

## 🚀 Технологический стек

- **React 18** + **TypeScript** - современный и типобезопасный фронтенд
- **Vite** - быстрый сборщик
- **Tailwind CSS** - утилитарные стили
- **lucide-react** - иконки
- **localStorage** - локальное хранилище данных

## 🎯 Использование

### Создание нового отчёта

1. Перейдите на вкладку **"Импорт данных"**
2. Укажите период отчёта (даты начала и окончания)
3. Заполните данные по категориям номеров:
   - Всего номеров
   - Заброни
   - Загрузка (%)
   - ADR (средний дневной тариф)
4. Заполните бухгалтерские данные:
   - Платежи
   - Расходы
5. Добавьте примечания (опционально)
6. Нажмите **"Создать отчёт"**

### Просмотр статистики

1. Перейдите на вкладку **"Dashboard"** для просмотра сводной информации
2. Используйте **"Отчёты"** для просмотра списка всех отчётов
3. Откройте **"Детальный анализ"** для углублённого изучения данных

### Работа с отчётами

- Выберите отчёт из списка для просмотра деталей
- Удалите ненужные отчёты кнопкой с иконкой корзины
- Сравнивайте периоды в разделе "Детальный анализ"

## 📊 Структура данных

Приложение поддерживает следующие разделы из отчётов bnovo.ru:

### Статистика номеров
- Всего номеров, доступно, заброни, свободно
- На ремонт, выведено
- Загрузка, ADR, RevPAR
- Заезды, выезды

### Статистика гостей
- Человеко/ночи, взрослые, дети
- Проживало, заехало, выехало
- Средний тариф, RevPAC

### Изменения бронирований
- Новые бронирования и их сумма
- Отменённые бронирования
- Процент отмен
- Не явки

### Источники бронирований
- Прямые
- Компания
- Агентства
- OTA (Online Travel Agencies)
- Модуль

### Бухгалтерия
- Платежи (по броне / без броне)
- Расходы
- Возвраты
- Долги (на начало / на конец)
- Прочие поступления

## 📈 Ключевые метрики

### ADR (Average Daily Rate)
Средний дневной тариф - средняя стоимость проданного номера за период

### RevPAR (Revenue Per Available Room)
Выручка на доступный номер - показатель эффективности управления доходами

### RevPAC (Revenue Per Available Customer)
Выручка на доступного клиента

### Загруженность
Процент занятых номеров от общего количества доступных

## 🔧 Технические детали

### Хранение данных
Все отчёты автоматически сохраняются в localStorage браузера под ключом `hotelReports`.

### Автоматические расчёты
- Суммарные показатели рассчитываются автоматически
- RevPAR вычисляется как ADR × Загруженность / 100
- Чистая прибыль = Платежи - Расходы

### Типизация
Полная типизация TypeScript для всех структур данных обеспечивает безопасность и удобство разработки.
